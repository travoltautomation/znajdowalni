# Zestaw logo Znajdowalni

## Pliki

- `znajdowalni-primary.svg` — podstawowy lockup z hasłem; hero, prezentacje, materiały szerokie.
- `znajdowalni-wordmark.svg` — sam logotyp; nagłówek strony, stopka, wizytówki.
- `znajdowalni-symbol.svg` — sygnet; avatar, pieczątka, element dekoracyjny.
- `znajdowalni-app-icon.svg` — favicon i ikona aplikacji na ciemnym tle.
- `znajdowalni-reverse.svg` — wersja na ciemne tło.
- `znajdowalni-mono-ink.svg` / `znajdowalni-mono-white.svg` — wersje jednokolorowe.

## Zasady użycia

- Kolory: Atrament `#0F1115`, Teal `#00B8B0`, Aqua `#BFEFEC`, Cloud `#FAFAF8`.
- Pole ochronne: minimum wysokość tealowego znaku wokół całego logo.
- Minimum: wordmark 120 px szerokości na ekranie; symbol 24 px; app icon 32 px.
- Nie rozciągaj, nie dodawaj cieni, gradientów ani dodatkowych kolorów do znaku.
- Logotyp opiera się o Montserrat Bold. Przed wysłaniem do druku zamień tekst na krzywe w programie DTP.
